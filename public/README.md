# Pasta de Logos e Ícones (Public)

Coloque as imagens da sua logomarca aqui dentro com os seguintes nomes:

- `logo-icon.png` -> Apenas o símbolo/balão (usado no Favicon da aba, Menu Lateral e Cabeçalhos)
- `logo-full.png` -> Logo completa com balão + Max Netminas (usada na tela de Login/Cadastro)
- `logo-text.png` -> (Opcional) Apenas a escrita Max Netminas
